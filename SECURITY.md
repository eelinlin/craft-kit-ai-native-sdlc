# Security

The hooks in this project are guardrails for an AI agent; a bypass is a security issue.

Please report vulnerabilities privately via GitHub's **Report a vulnerability** (Security tab) or
@eelinlin (GitHub), not in public issues. Include the hook, the input that bypassed it, and the
Claude Code version. We aim to respond within 7 days.

Scope notes: hooks reduce risk but are not a sandbox. For hard guarantees, combine them with
Claude Code permission rules, managed settings and sandboxing (see `admin/managed-settings.json`).
